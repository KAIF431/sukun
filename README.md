# SUKUN (سُكُون) — Islamic Spiritual AI & Quranic Sanctuary

> *"Verily, in the remembrance of Allah do hearts find rest."* — Surah Ar-Ra'd (13:28)

**SUKUN** is a luxury Islamic web application and AI companion engineered to bring inner peace (*Sukun*), authentic prophetic remedies, and Quranic wisdom directly to seekers in times of anxiety, grief, hope, and reflection.

---

## 🌟 Key Features

### 1. 🤖 Sukun AI Companion & Spiritual Search
- **Empathetic AI Guidance**: Speak your heart in natural language (Roman Urdu, English, Urdu) and receive comforting, respectful Islamic counsel rooted in the Quran and Sunnah.
- **Strict Islamic Adab**: Strictly filtered for respectful, gender-neutral spiritual mentorship — zero inappropriate, overly familiar, or misleading outputs.
- **Instant Dua Discovery**: Smart local fuzzy-match algorithm that instantly surfaces verified prophetic Duas before falling back to generative AI.

### 2. 📖 Daily Tilawat (Complete Quranic Surahs)
- **Surah Yaseen (سورة يس)** — Complete 83 Ayahs
- **Surah Al-Mulk (سورة الملك)** — Complete 30 Ayahs (The Protector from Grave)
- **Surah Al-Kahf (سورة الكهف)** — Complete 110 Ayahs (Friday Sunnah)
- **Ayat-ul-Kursi (آية الكرسي)** — Complete verse (Surah Al-Baqarah 2:255)
- **Dual Reading Modes**: 
  - *Card View*: Ayah-by-Ayah with Uthmani script, Urdu translation, English translation, and quick copy.
  - *Mushaf Continuous View*: Classic reading flow with inline Ayah markers.
- **Audio Recitation**: Integrated high-quality Tilawat audio player (Qari Mishary Rashid Alafasy).

### 3. 📿 Digital Tasbih Counter
- Multiple Dhikr options: *SubhanAllah (33)*, *Alhamdulillah (33)*, *Allahu Akbar (34)*, *Astaghfirullah (100)*, *La Ilaha Illallah*, *Salawat*.
- Elegant circular progress indicator, tactile tap feedback, cycle counter, and session memory.

### 4. 🎨 Dual Luxury Theme Engine
- **Dark Mode**: Midnight Sapphire, deep obsidian, and radiant celestial gold.
- **Light Mode**: Luminous warm pearl ivory, refined gold borders, and desert dusk typography.
- Seamless one-click theme switcher with persistent local storage preferences.

### 5. 🛡️ Admin Dashboard & Analytics
- Route: `/admin.html`
- Live AI latency benchmark and API key manager.
- Dua database browser and usage metrics.

## 🚀 Live Demo & Deployment

This project is built with vanilla HTML5, CSS3, and modern JavaScript (ES6+), making it 100% serverless and immediately deployable to **GitHub Pages**, **Vercel**, or **Netlify**.

### Deploying to GitHub Pages:
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select `Deploy from a branch`.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your live site will be accessible at:
   ```
   https://kaif431.github.io/sukun/
   ```
